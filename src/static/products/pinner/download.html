Installing Pinner Studio

  1. Download it and check itDownload Pinner Studio with the button above, and check its checksum (below).
  2. Run itWindows may show “Windows protected your PC” because the app is new and not yet widely downloaded. Choose More info → Run anyway.
  3. Allow the firewall promptThe first time it starts, Windows Firewall asks whether to let Pinner Studio talk on your network. Tick Private networks: that is how your phone finds it.
  4. Open the other appsOpen the Chrome extension and the Android app. They find Pinner Studio by themselves and ask you to tap Allow.

Check the download

Each release lists a SHA-256 checksum. In PowerShell run Get-FileHash .\PinnerStudio-Setup.exe -Algorithm SHA256 (use your file's name) and compare the result with the one on the release page.

Pinner Studio is for Windows only for now. Your library is a normal folder of images plus a small database, so you can always back it up or move it.
